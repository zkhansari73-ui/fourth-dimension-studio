# ابزار «ابعاد طلایی فضاها» — نسخه نهایی

## توضیح
ابزار تحت وب برای محاسبه ابعاد فضاها با نسبت طلایی (φ = ۱.۶۱۸).
فرمول: طول = √(مساحت × φ)، عرض = طول ÷ φ

## فلو کاربری
1. وارد کردن مساحت کلی (مترمربع)
2. انتخاب نوع ساختمان (۱۲ دسته: مسکونی، اداری، تجاری، آموزشی، درمانی، فرهنگی، ورزشی، اقامتی، صنعتی، مذهبی، دامی، فضای باز)
3. تیک زدن فضاهای موردنظر
4. تنظیم مساحت و تعداد هر فضا (توزیع خودکار متناسب با مساحت کلی)
5. دکمه «محاسبه ابعاد» → جدول نتایج (فضا | مساحت کل | طول هر واحد | عرض هر واحد)
6. دکمه «🖨️ چاپ نتایج»

## فایل‌ها
- `golden-standalone-final.html` — صفحه مستقل نهایی (نصب‌شده روی سایت)
- `golden.js` — نسخه یکپارچه قدیمی (کنار گذاشته شده، فقط برای آرشیو)

## تاریخچه نسخه‌ها
- v1: نسخه یکپارچه داخل tools.js (مشکل دراپ‌داون خالی)
- v2: صفحه مستقل با فلو مساحت کلی → فضاها → جدول (نصب ۲۰۲۶-۱۰-۱۹)
- v3: اضافه شدن تعداد (×n) + واژه‌های به‌روز معماری (لاندری، سوئیت مهمان...) (نصب ۲۰۲۶-۱۰-۱۹)
- v4: فیکس باگ‌های تعداد (نوار جمع + ابعاد هر واحد) + دکمه چاپ (نصب ۲۰۲۶-۱۰-۱۹)
- final: اضافه شدن متن حرفه‌ای «نسبت طلایی چیست؟ / کاربرد در معماری / چرا فضاها باید طلایی باشند؟» (نصب ۲۰۲۶-۱۰-۲۰)
