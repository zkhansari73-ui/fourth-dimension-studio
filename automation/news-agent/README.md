# عامل اخبار Fourth Dimension Studio

این عامل خبرهای تازه را از منابع تعریف‌شده جمع می‌کند، موارد قدیمی/تکراری/نامرتبط را کنار می‌گذارد، با اتصال فعلی Gemini در Composio اعتبار و اهمیت هر مورد را بررسی می‌کند و فقط خبرهای پذیرفته‌شده را به مقالهٔ مستقل انگلیسی، فارسی و عربی تبدیل می‌کند.

خروجی همیشه با وضعیت `Waiting Approval` و تأیید `Pending` در تب `News Pipeline` از فایل موجود `Fourth Dimension Content Automation` ذخیره می‌شود. اگر مقدار ستون تأیید به `Approved` تغییر کند، اجرای بعدی یک پیش‌نویس خصوصی در WordPress می‌سازد و لینک ویرایش را در ستون `AQ` ثبت می‌کند. این عامل هیچ‌گاه وضعیت WordPress را روی `publish` نمی‌گذارد.

## رفتار ایمن

- اجرای پیش‌فرض `NEWS_DRY_RUN=true` است و چیزی در شیت نمی‌نویسد.
- URLهای موجود در ستون E قبل از پردازش خوانده می‌شوند تا خبر تکراری ساخته نشود.
- تاریخ، ارتباط، منبع اصلی، امتیاز اهمیت و امتیاز ارتباط باید از آستانه عبور کنند.
- اگر خبر باکیفیت وجود نداشته باشد، هیچ مقاله‌ای تولید نمی‌شود.
- تصویر فعلاً به‌صورت `Image Prompt` و Alt Text آماده می‌شود. ساخت و بارگذاری خودکار تصویر تا زمان انتخاب یک ابزار تصویری متصل و آزمایش‌شده خاموش است.
- اتصال WordPress فقط برای ساخت `draft` استفاده می‌شود؛ انتشار نهایی همچنان دستی و نیازمند تأیید شماست.
- NotebookLM در این نسخه استفاده نمی‌شود، چون اتصال قابل‌اجرای آن در پروژه تأیید نشده است. Gemini خلاصه‌سازی مبتنی بر منبع و کنترل صحت را انجام می‌دهد.

## فعال‌سازی

1. `.env.example` را به `.env` کپی کنید.
2. `COMPOSIO_API_KEY` و شناسهٔ کاربر پروژه را فقط در محیط میزبان وارد کنید؛ کلید را در مخزن یا چت ذخیره نکنید.
3. ابتدا `npm run dry-run` را اجرا و گزارش را بررسی کنید.
4. پس از تأیید، `NEWS_DRY_RUN=false` کنید. این تغییر فقط نوشتن ردیف‌های `Waiting Approval` را فعال می‌کند، نه انتشار.

زمان‌بندی پیشنهادی روزانه در فایل workflow مخزن قرار دارد و پس از تعریف Secrets و فعال‌شدن GitHub Actions اجرا می‌شود.
