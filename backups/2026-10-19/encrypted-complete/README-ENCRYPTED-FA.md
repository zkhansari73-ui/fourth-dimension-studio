# بکاپ رمزگذاری‌شدهٔ کامل بسته‌های دریافت‌شده — ۱۹ اکتبر ۲۰۲۶

تمام پنج فایل اصلی (SQL، core، plugins، themes و uploads) در این پوشه موجودند: هفت بخش رمزگذاری‌شده به ۳۷۶ قطعه تقسیم شده‌اند و همه در parts ذخیره‌اند. هش Git هر قطعه هنگام ثبت با فایل محلی تطبیق داده شد. بازسازی آزمایشی محلی از ۳۷۶ قطعه به هفت بخش و کنترل SHA-256 هر هفت بخش موفق بود.

۱. همین شاخهٔ backup/site-state-2026-10-19 را clone یا دانلود کنید.
۲. داخل این پوشه اجرا کنید: python restore-github-backup.py
۳. کلید خصوصی recovery-key-20261019.txt را از پوشهٔ خصوصی Google Drive خود دریافت کنید؛ کلید در این مخزن وجود ندارد. شناسهٔ فایل کلید در encrypted-manifest.json ثبت است.
۴. Python 3 و بستهٔ cryptography برای رمزگشایی لازم است. اجرا: python decrypt-backup.py --key-file /path/to/recovery-key-20261019.txt --directory reconstructed-encrypted-backup --output decrypted-backup
۵. اسکریپت رمزگشایی پنج فایل اصلی را تولید و هش هرکدام را بررسی می‌کند. رمزگشایی محلی هر پنج فایل قبلاً آزمایش و با هش اصل تطبیق داده شده است.

پیش‌نویس Release فقط سه فایل قدیمی‌تر دارد؛ مرجع کامل همین پوشهٔ شاخه است. هیچ رمز یا کلید خام به GitHub ثبت نشده و main تغییر نکرده است.

دامنهٔ پوشش: بسته‌های تحویل‌شده شامل SQL با ۱۴ جدول، هسته و فایل‌های ریشه، قالب‌ها، افزونه‌ها و uploads است. صحت همهٔ فایل‌های زندهٔ هاست با فهرست مستقل تطبیق نشده؛ mu-plugins، drop-inها، فایل‌های دیگر wp-content، تنظیمات حساب هاست، DNS و ایمیل تأیید نشده‌اند. SQL در موتور پایگاه داده وارد نشده و راه‌اندازی کامل سایت آزمایشی انجام نشده است. پاک‌سازی یا مسدودکردن نسخه‌های موقت هاست و Muse هنوز تأیید نشده است. ذخیره‌سازی و سلامت بسته را با بازیابی کامل سایت اشتباه نگیرید.
